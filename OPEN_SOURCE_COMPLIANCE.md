# Open-Source Compliance

## Project license

No project `LICENSE` file was added because project copyright ownership was not confirmed in the repository evidence. MIT licensing remains NOT TESTED/NOT AUTHORIZED.

## Dependency licensing

The project uses MIT, BSD, PSF/BSD-derived, MPL-2.0, and LGPL-derived packages. Third-party licensing does not change merely because the project authors may choose MIT for their own source.

## Required release actions

1. Confirm the legal copyright holder and license for the project.
2. Add a top-level `LICENSE` containing the exact approved MIT text and confirmed year/copyright holder.
3. Generate or retain third-party notices for every distributed dependency and font.
4. Recheck licenses after dependency updates.
5. Include notices required by LGPL/MPL/BSD/PSF dependencies in the distributed artifacts.
